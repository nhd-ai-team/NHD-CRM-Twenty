# CRM 手册截图

截图与用户手册同样纳入 Git 管理，建议使用 PNG 格式，文件名按板块命名：

- `navigation/`：主导航和入口
- `conversation-workbench/`：对话工作台、AI 配置和接管流程
- `email/`：邮件详情、收发方向和引用历史
- `leads/`：线索重复提醒和线索操作
- `settings/`：个人渠道和 WhatsApp 绑定
- `login/`：登录页

截图只保留完成操作所需的区域，遮盖真实客户姓名、邮箱、电话、WhatsApp 和内部链接。每张图在正文附近配一句“在哪里”和一句“看什么”，不要把截图当作单独的操作说明。

当前图片已经按上述目录归档。功能迭代后，如果页面结构或按钮位置变化，应重新截取对应图片并保留稳定的英文文件名。
