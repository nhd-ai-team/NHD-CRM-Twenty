开始之前Before You Start

这套系统帮你做什么

一句话：把 WhatsApp、官网客服等多个渠道的客户消息统一到一个工作台，你在这里回复客户、把有价值的客户录成线索，并在 CRM 里一路推进到成交——不用再来回切换询盘云或其他 App。

你每天的主线工作流
步骤你做什么在哪里做
1收到客户消息（WhatsApp / 官网），及时回复对话工作台
2判断是有效客户 → 在右侧资料面板录成线索对话工作台 · 资料面板
3完善客户资料、技术信息、负责人CRM 线索 / 客户 / 项目
4记录跟进、推进线索阶段、转客户 / 转项目CRM 线索详情
阅读提示本手册聚焦核心日常操作。对话历史 / 沟通状态等历史数据查看、管理员后台深度配置、AI 高级话术策略等暂不在本手册范围内，后续单独培训。
01

登录与账号Login & Account

首次登录
  1. 收到邀请邮件
    管理员根据登记表，向你的邮箱发送一封 CRM 邀请邮件。点邮件里的链接进入系统。
  2. 自行设置密码
    首次进入时按提示自己设置登录密码（没有统一初始密码）。请设置一个只有你知道的专属密码。
  3. 登录系统
    之后访问 https://crm.chinanhd.com（建议用 Chrome / Edge），用邮箱 + 你设置的密码登录。
  4. 进入工作台
    登录成功后进入 CRM 主界面，左侧为导航栏，顶部可进入「对话工作台」。
忘记密码怎么办

有两条路，任选其一：

方式怎么做适用
自助邮件重置在登录页点「忘记密码」，输入邮箱 → 收到重置链接邮件 → 点开链接设置新密码。你还记得登录邮箱、邮箱能正常收信
找管理员重置联系后台管理员，管理员在后台为你重置一个新密码，再告知你。收不到邮件 / 情况紧急
注意只有后台管理员能帮别人重置密码；普通销售之间不能互相重置。重置后请第一时间改成自己的专属密码。
三种身份，能看到的数据不一样
身份可见范围典型权限
后台管理员全部数据管理成员、重置密码、查看所有销售的会话与线索
销售主管团队数据（规划中，逐步开放）查看团队成员的线索与会话
销售自己负责的数据处理自己的会话、维护自己负责的线索/客户
02

WhatsApp 绑定WhatsApp Binding

绑定后，你的 WhatsApp 客户消息才会进入对话工作台。每个人绑定自己的号。

绑定步骤
  1. 进入渠道设置
    点「设置 → 账户 → 渠道」，找到 WhatsApp 绑定区域。
  2. 发起绑定
    点「绑定 / 连接」，系统会显示一个二维码，或提供手机号配对码方式。
  3. 用手机扫码
    打开手机 WhatsApp →「已连接的设备 / Linked Devices」→ 扫描屏幕上的二维码（或输入配对码）。
  4. 确认绑定成功
    页面显示「已连接 / 在线」状态即为成功，之后客户消息会自动进入工作台。
🖼️
[ 截图待补充 ] 渠道设置页 + 扫码绑定界面 + 绑定成功状态
解绑 / 重新绑定
  • 换手机或需要停用时，在同一页面点「解绑 / 断开」即可。
  • 掉线后，重新进入渠道设置，重新扫码即可恢复。
重要注意
  • 一个 WhatsApp 号同一时间只能绑定一个 CRM 账号，不要多人共用一个号绑定。
  • 使用的是 WhatsApp 网页版连接方式，手机需保持联网，长时间关机 / 断网会导致掉线。
  • 个人号存在平台风控风险，不要短时间大量群发；主动外发请逐条、克制发送。
03

对话工作台Conversation Workspace

这是你处理客户消息的主战场——所有渠道的对话都在这里。

界面三大区
区域作用
① 会话列表（左）按最近消息排序，未读有角标；新消息实时置顶。可按联系人 / 号码搜索。
② 消息区（中）与当前客户的聊天记录，收发文字与附件都在这里。
③ 资料面板（右）客户资料 + 「更新线索」按钮，把这个客户录入 / 更新到 CRM 线索。
收发消息与附件
  1. 选中会话回复
    在左侧点开客户 → 在下方输入框打字 → 回车 / 点发送。
  2. 发送附件
    点输入框旁的附件按钮，选择文件（图片 / PDF / 文档等）发送给客户。
  3. 查看 / 下载客户发来的附件
    客户发来的文件直接在消息区显示，点击即可打开或下载，下载后文件名为客户原始文件名。
主动发起 WhatsApp 会话

需要主动联系一个还没聊过的客户时，可新建会话（搜索 / 输入号码发起）。

发送保护系统会校验你已绑定当前 WhatsApp 号、号码格式是否有效、渠道是否在线；任一不满足会明确提示原因。为防风控，仅支持人工逐条发起，不做批量群发。
人工接管

如果某个渠道开了 AI 自动回复（见下一章），当你手动介入回复时，该会话即由你接管、AI 停止自动回复。你随时可以直接接手任何一通对话。

AI 客服配置开关AI Auto-Reply Toggle

AI 智能客服可以在你不在时先接住客户。当前版本你在工作台只需管两个开关。

你能控制的两件事
开关作用
渠道级「自动回复」开 / 关决定这个渠道（如官网客服）是否由 AI 先自动回复客户。
每日生效时间段设定 AI 在每天哪个时间段自动回复（例如下班后、休息日）。

怎么用常见做法：上班时间关掉 AI 自己回，保证专业沟通；下班 / 节假日打开 AI，让客户不至于无人应答。你手动回复时会自动接管，AI 即停。

05

线索录入与推进Lead Entry & Pipeline

把有价值的客户变成 CRM 里的「线索（Opportunity）」，再一路推进——这是销售闭环的核心。

从对话录入线索
  1. 在资料面板填写客户信息
    右侧资料面板填：姓名、公司、WhatsApp、邮箱、国家、客户来源、公司类型、线索阶段、需求产品、备注等。
  2. 选择公司
    在公司字段搜索库内已有公司；搜不到就直接新建，避免重复建。
  3. 点「更新线索」
    信息写入 / 更新到 CRM 的 Opportunity。系统自动补齐线索编码、创建时间等。
看懂几个关键字段
字段含义
线索编码系统自动生成，格式如 NHD20260731001（NHD + 创建日期 + 当日流水号），无需手填。
客户来源标记从哪来（官网表单 / WhatsApp 等）。官网表单来的线索由系统自动建单并标注来源。
线索阶段反映跟进进度，随沟通逐步往前推。
负责人谁在跟这个客户。关系到数据可见范围，务必填对（详见第 06 章）。
转客户 / 转项目

线索谈得成熟后，可在线索列表顶部把它推进到下一环节：

  • 勾选目标线索 → 点顶部「转客户」→ 二次确认 → 生成对应客户（People）。
  • 类似地可「转项目」，进入项目跟踪。
  • 操作前有二次确认；若失败会弹出明确的失败原因，按提示处理即可。
提示官网询盘表单会自动建成线索并标注「客户来源 = 官网表单、进度 = 未处理线索」，你在线索列表就能直接看到，无需手工录入。
06

客户资料与技术信息维护Customer & Technical Info

把客户、公司、商机、项目关联起来，资料越完整，跟进越高效、交接越顺畅。

对象之间的数据关联

联系人、公司、商机 / 线索、项目之间共享一部分客户信息。当前主要通过「字段自动同步」保持这些信息一致——在一处更新，关联记录会自动带过去（详见本章最后「字段自动同步」）。

说明目前暂不支持在关联记录之间直接点击跳转，关联体现为数据自动同步，不是页面互相跳转。
负责人 / 协办人怎么填
字段含义影响
负责人这个客户/线索的主责销售决定谁能看到、谁在跟；数据归属的核心依据
协办人协助跟进的同事用于协作场景，可与主责一起跟进
务必填对负责人字段直接关系到数据可见范围（销售只看自己负责的）。负责人填错会导致该客户在你列表里消失，或别人看不到；离职交接时，把负责人改成新同事即可移交。
跟进记录（最新跟进）

跟进记录现在是一个富文本字段——在线索的「最新跟进」里直接编辑，可写多行、排版，记录本次沟通的进展。当前为富文本形式，不再是时间线视图。

按线索汇总附件

线索详情页有悬浮的「📎 附件」入口，点开可看到这个客户横跨所有渠道（WhatsApp、官网等）收发过的全部文件，方便回溯「这个客户前后发过哪些资料」。

🖼️
[ 截图待补充 ] 线索详情页「附件」悬浮入口 + 附件汇总弹窗
字段自动同步——填一处，多处生效

线索、客户、项目三张表之间，部分共享字段会自动互相同步（如联系人、国家、备注等）。你在一处更新，关联记录会自动带过去。

好处不用在多个地方重复录同一份资料。如果发现某个字段没同步过来或显示异常，先别反复手改，直接反馈给管理员排查，避免互相覆盖。
