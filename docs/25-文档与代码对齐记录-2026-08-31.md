## 2. WhatsApp 特殊消息

### 2.1 数据模型

服务启动时幂等增加以下字段：

| 字段 | 含义 |
|---|---|
| `conv.messages.raw_message_type` | WAHA / WhatsApp 原始消息类型，兼容 `payload.type`、`payload._data.type` 等位置 |
| `conv.messages.message_summary` | 面向 CRM 用户的可读摘要 |

### 2.2 当前识别规则

| 原始类型 | 摘要 |
|---|---|
| `reaction` / `reaction_message` | 客户发送了表情回应，并尽量带出表情内容 |
| `location` / `live_location` / `location_message` | 客户分享了位置 |
| `vcard` / `contact` / `contacts` / `multi_vcard` | 客户分享了联系人 |
| `poll_creation` / `poll` | 客户发起了投票 |
| `poll_update` | 客户回复了投票 |
| 其他未知类型 | 客户发送了暂不支持的 WhatsApp 消息（类型：`xxx`） |

普通文本、图片、视频、语音和文件继续按原有规则落库。重复 webhook 仍通过 `external_msg_id` 幂等去重。

### 2.3 历史数据边界

改动前已落库的 48 条 `content_type=unknown` 消息没有保存原始 WAHA payload，无法准确回溯具体类型；不对历史记录进行猜测性回填。新消息从本次服务重启后开始保存原始类型和摘要。

## 3. 对话工作台历史记录入口

`ChatPanel.jsx` 在会话头部右侧提供「查看历史记录」按钮。按钮优先调用同源父页面的 `window.parent.openHistoryPanel(conversationId)`，并以 `postMessage` 作为时序兜底。

历史面板由 `21-history-panel.js` 提供，支持：

- 当前会话消息关键词检索；
- 附件页签和附件链接查看；
- 关闭面板后保持当前对话上下文；
- 继续使用 `/conv-api/conversations/:id/messages`，受现有会话访问权限控制。
