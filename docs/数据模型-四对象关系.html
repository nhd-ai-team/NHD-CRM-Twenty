「公司名称」在方向 A 下的最终形态

公司名 · 数据流
公司(company.name) ——唯一真相—— 线索.companyId ⇄ 客户.companyId ⇄ 项目.companyId　（关系,显示"公司名称";二期项目已并入）
项目.name(公司名文本) ⇄ 客户.gongSiMingCheng　（文本对齐保留;公司真相以 companyId 关系为准）
线索.name ⇄ 公司名　← 方向 A 切断:线索主列归还给"联系人/访客"
  • 单一真相 = 公司对象:线索、客户都通过 company 关系挂到同一条公司记录,能去重、能聚合"这家公司名下所有线索/客户"。
  • 线索主列 name 按方向 A 归还给联系人/访客标识——底层 id 不动,只把基础 label 从遗留的"公司名称"统一成"访客ID/联系人",并切断它与公司名的同步(止血)。
  • 项目 xiangMu(二期已并入):新增 company(→公司)与 pointOfContact(→客户联系人)两个关系字段,并把 companyId 纳入三表同步——项目已彻底接入公司真相源。
    注:sourceOpportunity 本轮未做成关系字段,仍以 sourceOpportunityId 隐藏纽带列存在(与 person 一致,避免与受保护纽带列冲突/幽灵)。历史项目不回填,同步只对未来正确成组的记录生效。
  • 受保护字段:线索的 5 个官网表单字段 + 客户全部字段 + genJinJiLu 的底层 id 一律不动,本方案只改 label 与同步逻辑。
